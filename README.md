# CanvasLMS2Docsify

I will not be using this project anymore. I have started a new project with the same philosophy but more capabilities: [Canvas Local](https://github.com/lars-derichter/canvas-local)

Python script to export a Canvas LMS Course through the API into a directory structure with markdown files that can be used as the basis for a docsify site.
